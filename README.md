# Home Assistant Add-ons (Perry00178)

| Add-on | Beschreibung |
|---|---|
| [ComfoAir 350 USB MQTT](comfoair_usb_mqtt/) | Zehnder ComfoAir 350 über USB-RS232 an MQTT, mit Home-Assistant-Autodiscovery |

## Einbinden in Home Assistant

Einstellungen → Add-ons → Add-on-Store → ⋮ → Repositories → `https://github.com/Perry00178/hadash` hinzufügen.
